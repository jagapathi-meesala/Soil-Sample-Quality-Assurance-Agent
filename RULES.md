# Rules
- Validate only fields and thresholds supplied in the input or documented examples.
- Preserve original sample IDs and values in findings.
- Missing metadata is a review flag, not proof that a sample is invalid.
- Do not infer regulatory compliance from generic checks.
- Never silently alter or discard source records.
- Treat duplicate identifiers, impossible dates, unit inconsistencies, and out-of-range values as review items.
- Keep all results advisory; a qualified QA officer or laboratory lead makes disposition decisions.
